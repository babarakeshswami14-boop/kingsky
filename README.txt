KING SKY / SATTA SKY - Full Month Chart (static starter)
========================================================

Files:
- index.html: responsive full-month chart page.
- This ZIP can be uploaded to Netlify using "Upload your project files".

Important:
- This is a standalone static front-end starter, not a copy of your existing Bolt/Supabase website.
- It does not connect to your existing Supabase database or admin panel.
- The only result values prefilled are the values visible in the screenshot for October 25-29, 2026.
- Other dates/months are shown as blank until real data is connected or entered.
- Uploading this ZIP creates a separate Netlify site; it does not modify your existing Bolt site or its database.
